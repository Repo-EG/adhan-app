# 🕌 مواقيت الصلاة والأذان — Adhan App

برنامج مواقيت صلاة وأذان لسطح مكتب **ويندوز**، يعمل على أي مدينة أو محافظة في العالم.

A Windows desktop app for prayer times and Adhan, for any city in the world.

## ✨ المميزات
- مواقيت الصلاة الخمس لأي مدينة أو محافظة (بحث بالاسم، أو **تحديد الموقع تلقائيًا**).
- اختيار طريقة الحساب تلقائيًا حسب الدولة، أو يدويًا من 23 طريقة، مع مذهب حساب العصر.
- تعديل المواقيت يدويًا بالدقائق لمطابقة مسجدك أو التقويم الرسمي.
- التاريخ الهجري والميلادي، وعدّاد تنازلي للصلاة القادمة.
- تشغيل الأذان تلقائيًا، مع اختيار مؤذن لكل صلاة، ووضع «التكبير فقط».
- يعمل بدون إنترنت باقي الشهر بعد جلب الجدول مرة واحدة.
- واجهة عربية/إنجليزية، ووضع فاتح وداكن.
- يعمل في الخلفية بأيقونة بجانب الساعة، فيشغّل الأذان حتى لو أغلقت النافذة.
- إشعار داخل البرنامج عند توفر إصدار جديد.

## 📥 التحميل والتثبيت
1. من صفحة **[Releases](../../releases/latest)** حمّل ملف `AdhanApp-Setup-x.y.z.exe`.
2. شغّله واتبع خطوات التثبيت (لا يحتاج صلاحيات مدير). يبدأ المعالج باختيار اللغة (العربية/English). يمكنك اختيار اختصار سطح المكتب والتشغيل مع ويندوز.
3. افتح البرنامج من قائمة **Start** أو من سطح المكتب.

لتحديث البرنامج: عند ظهور شريط التحديث 🔔 داخل البرنامج، حمّل الإصدار الجديد وشغّله فوق القديم، وتبقى إعداداتك كما هي.
لإلغاء التثبيت: **الإعدادات ← التطبيقات** في ويندوز.

### 🔊 ملفات الأذان
أضف ملفات الأذان من **الإعدادات ← الملفات ← إضافة ملفات صوتية** (أي ملف MP3 دون تغيير اسمه).
أو ضعها يدويًا في مجلد `adhan` عبر اختصار **Adhan App - Adhan audio files** في قائمة Start
(وللتكبير فقط: مجلد `takbeer`). الخلفية هي ملف `wall.png` فقط (ضعه بجوار البرنامج قبل البناء).

إن حدثت مشكلة افتح ملفي `adhan_log.txt` و`adhan_crash.txt` داخل مجلد البرنامج وأرسله لنا.

> ⚠️ قد يعرض ويندوز تحذير SmartScreen لأن البرنامج غير موقّع رقميًا. اضغط **Run anyway ← More info**.
> الكود مفتوح المصدر هنا ليمكنك مراجعته.

## 🔒 الخصوصية
البرنامج لا يرسل أي بيانات شخصية لنا. يتصل بالخدمات التالية فقط عند الحاجة:
- [Aladhan](https://aladhan.com) لجلب جدول المواقيت (يرسل إحداثيات المدينة).
- [Open-Meteo](https://open-meteo.com) للبحث عن المدن.
- [OpenStreetMap Nominatim](https://nominatim.org) و [ipwho.is](https://ipwho.is) فقط عند الضغط على «تحديد موقعي تلقائيًا».
- GitHub لفحص وجود إصدار جديد.
